# 📋 Lista Inteligente

App de lista de compras inteligente feito para rodar 100% offline no GitHub Pages.

## 🚀 Funcionalidades
- Checklist com progresso
- Modo mercado
- Vibração no celular
- Histórico local
- PWA (instalável)
- Funciona sem internet

## 📱 Instalação
Abra o site no celular e toque em **“Adicionar à tela inicial”**

## 🛠️ Tecnologias
- HTML
- CSS
- JavaScript puro
- Service Worker
- LocalStorage
